### Hi, I'm Matthias 👋

I build software for data from the real world: animal tracking, sensors, large movement datasets, and the pictures that
make them understandable. Managing Director of [Schäuffelhut Berger GmbH](https://www.schaeuffelhut-berger.de/?ref=github)
in Munich.

- **Movebank:** core developer of [Movebank](https://www.movebank.org)'s software from 2008 to 2025 (Movebank is run by
  the Max Planck Institute of Animal Behavior).
- **Firetail:** I develop [Firetail](https://www.firetail.de/?ref=github), desktop software for GPS, accelerometer and
  behaviour data of tagged animals (Windows, macOS, Linux, free edition available).
- **Visualization:** my animations of Movebank data have been shown on German TV, printed in books and exhibited at the
  Frankfurter Kunstverein. Six of them are published as appendices to a paper in _Ecosphere_.
  [How they are made, and where they appeared](https://www.schaeuffelhut-berger.de/en/blog/global-animal-migration/?ref=github)

### Movebank tooling (Java / R, open source)

One toolchain to work with Movebank data offline:

| Repo | What it does |
|---|---|
| [movebank-api-client](https://github.com/mcb77/movebank-api-client) | Java client for the Movebank REST API |
| [movebank-mirror](https://github.com/mcb77/movebank-mirror) | Mirrors Movebank studies to plain files on your disk; resumable, incremental |
| [movebank-mirror-api](https://github.com/mcb77/movebank-mirror-api) | Serves the Movebank REST API from a local mirror, a drop-in for `move`/`move2` and the Java client |
| [movebank-rocker](https://github.com/mcb77/movebank-rocker) | Pinned R environment (rocker/geospatial + move, move2, moveVis, sf) |

Background: [Keep a Movebank study on your own computer](https://www.schaeuffelhut-berger.de/en/blog/keep-a-movebank-study-on-your-own-computer/?ref=github)
